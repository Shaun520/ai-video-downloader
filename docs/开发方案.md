# 开发方案（当前版本）

> 记录时间：2026-09-14
> 说明：本文档记录项目当前（改造前）的开发方案，作为改造的参照基线。

## 一、项目简介

AI 万能视频下载总结器（SaveAny）：输入一个视频链接，自动解析视频信息，支持 B 站、YouTube、抖音等 1800+ 平台视频下载，并提供 AI 视频总结（摘要 + 思维导图 + 问答）、字幕导出、用户认证（JWT）与 Stripe 国际支付。

来源：[free-video-downloader](https://github.com/liyupi/free-video-downloader)（已在本地以 `video-downloader` 为名克隆）。

## 二、技术栈

| 端 | 技术 |
|----|------|
| 前端 | Vue 3.5 + Vite 7 + Tailwind CSS 4 + axios + markmap + marked |
| 后端 | Python 3.13 + FastAPI + Uvicorn + yt-dlp + OpenAI SDK(DeepSeek) + PyJWT + bcrypt + Stripe |
| 数据库 | SQLite（本地文件 `backend/data/app.db`，启动自动建表） |

## 三、目录结构

```
video-downloader/
├─ backend/                 FastAPI 后端
│  ├─ main.py               路由入口：parse / download / direct-url / 缩略图代理
│  ├─ downloader.py         yt-dlp 通用解析下载封装
│  ├─ douyin.py             抖音专用解析模块（免 Cookie 无水印）
│  ├─ summarizer.py         字幕提取 + DeepSeek 总结/思维导图/问答（SSE 流式）
│  ├─ auth.py               bcrypt + JWT 认证
│  ├─ database.py           SQLite：users / orders 表 + 每日次数/VIP 逻辑
│  ├─ api_auth.py           注册登录 API
│  ├─ api_payment.py        Stripe 支付 API
│  └─ api_summarize.py      AI 总结 SSE API
├─ frontend/                Vue 单页应用
│  └─ src/
│     ├─ components/        营销页 + VideoResult + VideoSummary + AuthModal 等
│     └─ api/               auth / payment / summarize / video
└─ docs/                    文档
```

## 四、核心功能模块

1. **多平台解析下载**：yt-dlp 支持 1800+ 网站；抖音走专用模块免 Cookie 拿无水印视频
2. **AI 视频总结**：字幕提取 → DeepSeek 大模型流式生成摘要（Markdown）
3. **AI 思维导图**：基于字幕内容生成 markmap 交互式导图（可导出 PNG/SVG）
4. **AI 视频问答**：基于字幕文本回答用户问题
5. **字幕导出**：SRT / VTT / TXT
6. **用户认证**：邮箱密码 + JWT 无状态认证；免费用户每日 3 次 AI 总结，VIP 不限次
7. **Stripe 支付**：VIP 会员开通（本地未配置，不影响核心功能）

## 五、启动方式

### 前置条件

- Python ≥ 3.10（本机 3.13.2 ✅）
- Node.js ≥ 18（本机 v24.9.0 ✅）
- ffmpeg（本机 9.0.1 ✅，音视频合并用）
- DeepSeek API Key（必需，AI 总结用）
- Stripe 配置（可选，VIP 支付用）

### 配置环境变量

```bash
cd backend
cp .env.example .env
# 编辑 .env 填入：
#   DEEPSEEK_API_KEY=sk-xxxx       必填
#   JWT_SECRET=xxx                  必填（本地随意）
#   STRIPE_* / FRONTEND_URL         选填
```

### 启动（两个终端）

```bash
# 终端 1：后端（端口 8000）
cd backend
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
python main.py

# 终端 2：前端（端口 5173）
cd frontend
npm install --registry=https://registry.npmmirror.com
npm run dev
```

访问 http://localhost:5173 ；后端 API 文档 http://localhost:8000/docs
